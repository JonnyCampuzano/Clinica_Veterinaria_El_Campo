# Sistema Veterinario El Campo

## Cómo ejecutar

1. Copia la carpeta `ElCampo` dentro de:
   `C:\xampp\htdocs\`

2. Abre XAMPP y activa:
   - Apache
   - MySQL

3. Entra a phpMyAdmin:
   `http://localhost/phpmyadmin`

4. Importa el archivo:
   `database/elcampo_veterinaria.sql`

5. Abre:
   `http://localhost/ElCampo/login.php`
